API & System Integration

1. Recording Usage (POST)

Use this endpoint to log every token transaction from your AI agents.

POST /api/usage

Request Body (JSON)

{
  "agent_name": "Customer-Service-Bot",
  "model_name": "google/gemini-1.5-flash",
  "input_tokens": 120,
  "output_tokens": 450,
  "total_tokens": 570,
  "cost": 0.000085
}

Validation Rules

  • agent_name: String (Required)
  • model_name: String (Required - Use OpenRouter ID)
  • total_tokens: Integer (Required)
  • cost: Numeric (Required - Recommended 6 decimal places)

2. Analytics Retrieval (GET)

Fetch processed analytics, trends, and filtered data.

GET /api/analytics

Query Parameters

  • range: "all", "7days", "30days", "custom"
  • agent: Filter by specific agent name
  • model: Filter by specific model ID
  • start / end: YYYY-MM-DD for custom range

Response Data

Returns an object containing stats (totals, efficiency, ratios), charts (trends, distributions), and raw_data (latest logs).

3. Real-time Polling

The dashboard uses an active polling mechanism to keep data fresh. By default, it requests new analytics every 5 seconds. This ensures that the "Latest Activity" log and all charts reflect recent transactions without manual refreshes.
